# Chat App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a production-oriented full-stack chat web app per `docs/specs.md`.

**Architecture:** Modular monolith on Next.js 16 App Router — RSC shell + thin route handlers and Server Actions funneling into shared `services/` → `repositories/` → Drizzle → Turso SQLite. Better Auth (credentials-only, DB sessions) for auth; TanStack Query polling for freshness; Zod schemas double as OpenAPI source.

**Tech Stack:** Next.js 16, TypeScript strict, Tailwind 4, shadcn/ui, next-intl, next-themes, Better Auth, Drizzle + @libsql/client (Turso/file fallback), Zod, zod-openapi, @scalar/nextjs-api-reference, Zustand, TanStack Query, Vitest, Playwright, Biome, Pino, @vercel/otel, pnpm, mise.

**Spec:** `docs/specs.md` (requirements) + `docs/superpowers/specs/2026-10-17-chat-app-design.md` (approved design). Both travel with this plan; read them first.

## Global Constraints

- Node `24`, pnpm `10` via `mise.toml`. Committed `pnpm-lock.yaml`; `pnpm install --frozen-lockfile` in CI.
- Next.js `16.x` — pin latest stable discovered via `pnpm view next versions` at scaffold time; never invent a version. React = the version Next 16's template pins.
- TypeScript `strict`; no `any`, no unsafe assertions.
- UTC ms integer timestamps; uuid v7 text PKs.
- Server-only code (db, auth config, logger, env) must never be imported into client components — enforce via `server-only` package on `src/lib/db`, `src/lib/env`, `src/lib/auth`, `src/lib/logging`.
- All user-facing strings live in `messages/en.json` + `messages/vi.json`; none hardcoded.
- IDs from `crypto.randomUUID()` are v4 — fine, but call the generator `newId()` in `src/lib/db/id.ts` so it stays swappable.
- Message body limit: **4000 chars**, enforced Zod-side AND `CHECK (length(body) <= 4000)` in SQL.
- Cursor = base64url JSON `[createdAt, id]`; never timestamp-only ordering.
- Conventional commits. Commit at every task end; `git` commands shown are exact.
- No new dependencies beyond this plan's list without flagging in the task's commit message.
- Env vars (only these exist): `DATABASE_URL` (default `file:./dev.db`), `DATABASE_AUTH_TOKEN` (optional; Turso only), `BETTER_AUTH_SECRET` (required in prod), `BETTER_AUTH_URL` (default `http://localhost:3000`), `LOG_LEVEL` (default `info`), `OTEL_EXPORTER_OTLP_ENDPOINT` (optional).

const buckets = new Map<string, number[]>();
export function rateLimit(key: string, limit: number, windowMs: number): boolean {
  const now = Date.now();
  const hits = (buckets.get(key) ?? []).filter((t) => now - t < windowMs);
  if (hits.length >= limit) return false;
  hits.push(now);
  buckets.set(key, hits);
  return true;
}

export function encodeCursor(createdAt: number, id: string) {
  return Buffer.from(JSON.stringify([createdAt, id])).toString("base64url");

export function decodeCursor(cursor: string) {
  try {
    const v: unknown = JSON.parse(Buffer.from(cursor, "base64url").toString());
    if (Array.isArray(v) && typeof v[0] === "number" && typeof v[1] === "string")
      return { createdAt: v[0], id: v[1] };
